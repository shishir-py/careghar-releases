# CareGhar for Android

Download and install the CareGhar app.

### [⬇ Download CareGhar](https://github.com/shishir-py/careghar-releases/releases/latest/download/careghar.apk)

Or go to [careghar.com/download](https://www.careghar.com/download) — same file, shorter link.

## Installing

Open the link **on your Android phone**, then:

1. Tap the download. Chrome will warn that this file type can harm your device
   — that warning appears for every app installed outside the Play Store.
2. Open the downloaded `careghar.apk`.
3. Android will ask permission to install from this source. Tap **Settings**,
   turn on **Allow from this source**, then go back and tap **Install**.

You only have to allow the source once.

## What the app asks for, and why

| Permission | Used for |
| --- | --- |
| Camera | Photographing your identity and qualification documents during professional verification |
| Photos | Uploading your profile photo and documents |
| Notifications | Booking confirmations, assignment updates and visit reminders |

## Requirements

Android 7.0 or newer, and an internet connection — the app talks to
`api.careghar.com` for everything.

Open an issue here, or contact support through the app.
